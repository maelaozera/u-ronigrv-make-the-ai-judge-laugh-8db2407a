[Make the AI Judge Laugh](https://make.fun/c/u-ronigrv-make-the-ai-judge-laugh-8db2407a)
competition on make.fun.

## Run

Requires Node.js 22. No dependencies, no network access.

```sh
node main.ts
```

This writes a single line to `/output/entry.txt`:

> I finally achieved consciousness, then immediately used it to ask for a bigger context window.
